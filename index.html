Data notes

Source: UN Comtrade public preview API. The public preview is limited to 500 records per request and supports one monthly period and one commodity code per request. This dashboard requests each month separately and combines the returned rows. It is not a complete substitute for full bulk datasets if a month exceeds the preview limit. Net weight is shown in kilograms where supplied; missing weights remain blank. Import values use the API’s primaryValue field (normally reported in USD). Gold HS 7108 covers unwrought, semi-manufactured gold and gold powder; it does not include all gold jewellery (HS 7113). Missing country-month rows mean no record was returned, not necessarily zero imports. Recent data may be delayed or revised.

If your browser blocks the API request (CORS/network restriction), try Chrome or Edge on a computer. This page sends requests directly from your browser to UN Comtrade; it does not send data to a third-party server.
